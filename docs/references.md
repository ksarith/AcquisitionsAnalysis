# References and Candidate Improvements

Outside reading that bears on this framework. Nothing here is enacted by reading it: candidate changes below enter the question set only through backtesting and a change log entry, per the calibration rule.

## Read

- [Wharton: Why Many M&A Deals Fail](https://knowledge.wharton.upenn.edu/article/why-many-ma-deals-fail-and-how-to-beat-the-odds/) - argues for staged screening with deal breakers established upfront (regulatory, cultural misalignment, technology incompatibility); documents the Verizon/Yahoo price cut after undisclosed data breaches were found in late diligence.
- [Affinity: Why most M&A destroys value](https://www.affinity.co/blog/why-most-m-a-deals-fail-integration) - cites a 40,000-deal study: 70 to 75% fail to create value, with a large share blamed on integration rather than strategy; argues integration capability is assessable before close.
- [DealRoom: Post Merger Integration](https://dealroom.net/faq/post-merger-and-acquisition-m-a-integration-process) - poor integration practice named as the leading cause of PMI failure.
- [Ansarada: Post-Deal Integration Checklist](https://www.ansarada.com/post-deal-integration-checklist) - integration planning should start during due diligence, not after completion.
- [M&A Community: integration guide](https://mnacommunity.com/insights/post-merger-integration-guide/) - cites PwC M&A Integration Survey: only 14% reported significant integration success.

## What the framework already covers

The two-gate design (breakers first, scored dimensions second) matches the staged-screening recommendation. B1 (regulatory), D3 (technology), D7 (integration and people with culture overlap) map onto the fail-cases above.

## Candidate improvements (not enacted; test on real deals first)

- **C1. Cybersecurity and data posture.** No breaker or dimension currently asks whether the target has undisclosed breaches, weak security posture, or material data liabilities. The Yahoo case shows this can move price mid-deal. Candidate: add a breaker or a probe under B4 (uncapped liabilities) plus a D4 check.
- **C2. Acquirer integration capability.** D7 asks about the plan but not whether the acquirer has successfully integrated a deal before. Candidate question for D7: has this acquirer completed a comparable integration, and what happened?
- **C3. Culture clash as a scored item.** Culture appears in D7 as overlap only. Candidate: split a dedicated question on assessable culture evidence (exit data, engagement scores, leadership overlap) from general footprint overlap.
- **C4. Integration start before close.** Candidate D7 probe: is integration planning already underway at announcement, with a named lead and authority?
